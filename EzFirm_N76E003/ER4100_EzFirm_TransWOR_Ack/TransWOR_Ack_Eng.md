# ER4100_EzFirm_TransWOR_Ack

## Overview

This project extends `ER4100_EzFirm_TransWOR` by adding an **ACK response**.

After receiving a valid packet via WOR, the device sends a 3-byte `"ACK"` payload back to the sender, waits for TX completion, then re-enters the WOR deep sleep cycle.

---

## WOR + ACK Flow

```
XTAPP_Init()
  │  SPI init → SW reset → TRx_Init() → 3s stabilization delay
  └─► XTAPP_WOR_Trigger()
        │  Set WUT period (100ms) + RX window (WOR_CNT × WOR_CNT_UNIT)
        │  Reset RX FIFO → TRx_RX_Trigger()
        └─► TRx_PowerDownMode()  ← deep sleep

    [ER4100 wakes up every 100ms, opens 80ms RX window]

NIRQ asserted
  └─► XTAPP_IrqHdlr()
        ├─ IS_INT_ST_ANY_RX  → XTAPP_WOR_Disable()
        │                       Read FIFO + RSSI → dump_buffer()
        │                       XTAPP_WOR_Pkt_Proc()   ← send ACK
        │                         │  Delay 200ms (wait for remote RX restart)
        │                         │  Fill "ACK" → XTAPP_SendData()
        │                         │  Poll NIRQ until TX done
        │                         └─► XTAPP_WOR_Trigger()  ← restart
        └─ other INT         → RX FIFO reset
                                XTAPP_WOR_Trigger()  ← restart
```

---

## Difference vs TransWOR

[收到封包时]
  TransWOR     : Restart WOR immediately
  TransWOR_Ack : Send ACK first, then restart WOR
[ACK content]
  TransWOR     : —
  TransWOR_Ack : 3 bytes: `'A'`, `'C'`, `'K'`
[ACK delay]
  TransWOR     : —
  TransWOR_Ack : 200 ms (wait for remote RX to be ready)
[TX completion]
  TransWOR     : —
  TransWOR_Ack : Polling NIRQ (`while(NIRQ_Value)`)
[New function]
  TransWOR     : —
  TransWOR_Ack : `XTAPP_WOR_Pkt_Proc()`

## WOR Parameters

[WOR Parameters]
  `WOR_CNT`          : 4  (RX window count)
  `WOR_CNT_UNIT`     : 3  (Unit = 20 ms)
  RX window duration : 80 ms  (WOR_CNT × 20ms)
  WUT period         : 100 ms  (`SET_WUT_PERIORD_ARRAY_100MS`)

To change the WUT period, modify `WUT_PERIOD_SEL` in `RF_App.c`:

```c
#define WUT_PERIOD_SEL(arr)   SET_WUT_PERIORD_ARRAY_100MS(arr)
// Available: 10MS / 50MS / 100MS / 500MS / 1S / 2S / 4S
```

WUT register value formula: `Register = (Period_ms × 32768) / 1000`

> **Note:** WOR requires `EXTERN_RF_APIS_WUT` to be defined in `SPI_ER41xx_config.h`:
> ```c
> #define EXTERN_RF_APIS_WUT
> ```
> Without this define, WUT-related APIs such as `TRx_RX_WUTMR_Enable()` and `TRx_SetWUTMR_Timer()` will not be compiled in.

### GPIO1 TR_BSY Output (RX Window Measurement)

The `SPI_ER41xx_config.h` in this example pre-configures **GPIO1 as TR_BSY output**.
TR_BSY is asserted high by the ER4100 while the RX window is open and de-asserted when the chip returns to sleep.
Probing GPIO1 with an oscilloscope or logic analyzer allows direct observation of the RX window timing.

```
reg 0x4004 = {0x06, 0x01, 0x16, 0x00}  ← GPIO1 configured as TR_BSY
```

## Key API Functions

[Key API Functions]
  `XTAPP_Init()`           : Initialize SPI, verify chip ID, start WOR
  `XTAPP_WOR_Trigger()`    : Set WUT period + RX window, enter deep sleep
  `XTAPP_WOR_Disable()`    : Stop WOR timer before sending ACK
  `XTAPP_WOR_Pkt_Proc()`   : Send ACK after RX, poll for TX done, restart WOR
  `XTAPP_IrqHdlr()`        : Handle NIRQ: process RX + ACK, or handle other events
  `XTAPP_ReceiveCheck()`   : Read RX data length and FIFO contents
  `XTAPP_SendData()`       : Disable RX, write TX FIFO, trigger TX
  `XTAPP_Scan()`           : Main loop polling: returns if init failed, calls `XTAPP_IrqHdlr()` on NIRQ low

### Startup UART Log

On power-up, `main.c` outputs the project name and init result via UART:

  "TransWOR_Ack : init done\r\n"  — initialization successful
  "TransWOR_Ack : init fail\r\n"  — initialization failed

### XTAPP_Scan() Error Guard

`XTAPP_Scan()` returns immediately if `rf_err_mode == 1` (init failed), preventing RF access when the transceiver is not initialized.
