# ER4100_EzFirm_PowerSaving_WUT Project Structure

## Overview

This project demonstrates **WUT (Wakeup Timer) oneshot mode** for the ER4100 RF transceiver.

On initialization the chip enters deep sleep immediately. The WUT timer fires after the configured interval (default 2 seconds), asserts NIRQ, and the MCU wakes up, prints a UART message, resets the WUT timer, and re-enters deep sleep. This cycle repeats indefinitely.

There is no RF packet TX or RX in this project. It is a minimal demonstration of the WUT timer and deep-sleep flow only.

> **Note:** `EXTERN_RF_APIS_WUT` must be defined in `SPI_ER41xx_config.h` to enable the WUT timer APIs (`TRx_SetWUTMR_Timer`, `TRx_PowerDownMode`, etc.).

## Extended Notes

### Common.h as the Single Include Entry
All `.c` files only need `#include "Common.h"` to get all typedefs, MCU headers, and module declarations.

### SPI Implementation
Uses **Software SPI (GPIO bit-bang)**. Pin definitions are centralized in `RF_Hal.h`:

[SPI Pin Assignment]
  NIRQ  P03  Interrupt input (WUT wakeup signal)
  MOSI  P00  SPI data output
  MISO  P01  SPI data input
  SCK   P10  SPI clock
  NSS   P15  SPI chip select

### WUT (Wakeup Timer) — Oneshot Mode

The WUT timer is configured in **oneshot mode**: each time the timer expires it fires once, asserts NIRQ, and stops. The firmware manually restarts the timer on each wakeup.

[WUT Flow]
  XTAPP_Init()
    │  TRx_SetWUTMR_Timer(period, 0)  ← oneshot mode (repeat=0)
    │  TRx_PowerDownMode()            ← enter deep sleep
    ▼
  (chip sleeps for WUT_PERIOD)
    ▼
  NIRQ asserted → XTAPP_Scan() called
    │  TRx_GetIntStatus() → IS_INT_ST_WAKEUP
    │  UART0_SendStr("Wakeup...")
    │  TRx_SetWUTMR_Timer(period, 0)  ← restart oneshot
    │  TRx_PowerDownMode()            ← re-enter deep sleep
    ▼
  (repeat)

[WUT Period Macros]
  SET_WUT_PERIORD_ARRAY_10MS   0x00000147   ~10 ms
  SET_WUT_PERIORD_ARRAY_50MS   0x00000666   ~50 ms
  SET_WUT_PERIORD_ARRAY_100MS  0x00000CCC   ~100 ms
  SET_WUT_PERIORD_ARRAY_500MS  0x00004000   ~500 ms
  SET_WUT_PERIORD_ARRAY_1S     0x00008000   ~1000 ms
  SET_WUT_PERIORD_ARRAY_2S     0x00010000   ~2000 ms
  SET_WUT_PERIORD_ARRAY_4S     0x00020000   ~4000 ms

  WUT_PERIOD_SEL selects the active period. Default: SET_WUT_PERIORD_ARRAY_2S (2 seconds).

Period formula: Register_Value = (Period_ms × 32768) / 1000

### Startup UART Log

On power-up, `main.c` outputs the project name and init result via UART:

  "PowerSaving_WUT : init done\r\n"  — initialization successful
  "PowerSaving_WUT : init fail\r\n"  — initialization failed

### XTAPP_Scan() Error Guard

`XTAPP_Scan()` returns immediately if `rf_err_mode == 1` (init failed), preventing RF access when the transceiver is not initialized.

### EXTERN_RF_APIS_WUT

The WUT APIs (`TRx_SetWUTMR_Timer`, `TRx_PowerDownMode`) are conditionally compiled and require the following define in `SPI_ER41xx_config.h`:

```c
#define EXTERN_RF_APIS_WUT
```

Without this define, the WUT functions will not be compiled and the linker will report missing symbols.

### IS_INT_ST_TMRTHD vs IS_INT_ST_WAKEUP

Two interrupt flags may be asserted on a WUT wakeup event:

[Interrupt Flags]
  IS_INT_ST_TMRTHD  : Timer threshold reached (optional, can be ignored)
  IS_INT_ST_WAKEUP  : Chip wakeup event — use this to detect actual wakeup

The firmware logs "Wakeup Timer\r\n" for TMRTHD and "Wakeup, and enter deep sleep again...\r\n" for WAKEUP.
