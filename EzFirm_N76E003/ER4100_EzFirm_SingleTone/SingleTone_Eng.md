# ER4100_EzFirm_SingleTone

## Overview

This project demonstrates **Single Tone (continuous carrier wave)** testing with the ER4100 RF transceiver on an N76E003 (8051) MCU.

On initialization the chip enters Single Tone mode automatically. Press P0.5 to stop transmission; press again to restart. This is useful for measuring RF carrier frequency, output power, or debugging the antenna. There is no packet TX or RX in this project.

## Single Tone Flow

```
Power-on
  └─► XTAPP_Init()
        │  SPI init → Chip ID check → TRx_Init()
        └─► rf_single_tone_state = st_start  (default: auto-trigger on startup)

First scan loop iteration
  └─► XTAPP_Scan()
        │  state == st_start
        │  UART: "Single Tone Start\r\n"
        │  TRx_SingleTone_Trigger()   ← begin continuous carrier TX
        └─► rf_single_tone_state = st_launching

Press P05 (while transmitting)
  └─► XTAPP_Scan()
        │  non-stop state → st_stop
        │  state == st_stop
        │  UART: "Single Tone Stop\r\n"
        └─► TRx_SingleTone_Disable()

Press P05 (while stopped)
  └─► XTAPP_Scan()
        │  st_stop → st_start
        │  UART: "Single Tone Start\r\n"
        └─► TRx_SingleTone_Trigger()
```

State machine: `st_stop` ↔ `st_start` → `st_launching` (transmitting)

## Extended Notes

### Common.h as the Single Include Entry
All `.c` files only need `#include "Common.h"` to get all typedefs, MCU headers, and module declarations.

### SPI Implementation
Uses **Software SPI (GPIO bit-bang)**. Pin definitions are centralized in `RF_Hal.h`:

[SPI Pin Assignment]
  NIRQ  P03  Interrupt input
  MOSI  P00  SPI data output
  MISO  P01  SPI data input
  SCK   P10  SPI clock
  NSS   P15  SPI chip select

### GPIO — Application Pins

[GPIO — Application Pins]
  P05  Push-pull  Single Tone control button (active-low, toggles start/stop)

### Startup UART Log

On power-up, `main.c` outputs the project name and init result via UART:

  "SingleTone : init done\r\n"  — initialization successful
  "SingleTone : init fail\r\n"  — initialization failed

### XTAPP_Scan() Error Guard

`XTAPP_Scan()` returns immediately if `rf_err_mode == 1` (init failed), preventing RF access when the transceiver is not initialized.
