# ER4100_EzFirm_TransTxRx_PER

## Overview

This project demonstrates **Packet Error Rate (PER) measurement** in transparent mode with the ER4100 RF transceiver on an N76E003 (8051) MCU.

Pressing the button (P0.5) triggers a burst of **500 TX packets** at 50 ms intervals.
The receiving side verifies each packet via a software XOR checksum and accumulates ok/error counts.
A **running PER** is printed to UART after every received packet, and a final PER summary is printed when 500 packets have been tallied.

**Difference vs TransTxRx:**

| | TransTxRx | TransTxRx_PER |
|---|---|---|
| TX trigger | Single packet per P05 press | Burst of 500 packets per P05 press |
| TX interval | Immediate | 50 ms between packets |
| Payload | User pattern | seq[2] + pattern + XOR checksum |
| RX action | Print data + RSSI | Verify checksum, count ok/error, print running PER |
| PER report | — | Running % per packet + final summary at 500 |

---

## TX Packet Format

Each transmitted packet uses the standard transparent mode payload:

```
[seq_hi][seq_lo][data_0]...[data_N-2][XOR]
```

- `seq_hi / seq_lo` : 2-byte big-endian sequence number (0~499)
- `data_0 ~ data_N-2` : sequential fill bytes (`i & 0xFF`)
- `XOR` : last byte — XOR of all preceding bytes in the payload (checksum)

---

## RX Verification and PER Calculation

On each received packet the IRQ handler (`XTAPP_IrqHdlr`):

1. Reads payload from FIFO
2. Recomputes XOR of bytes `[0 .. N-2]`
3. Compares with received `payload[N-1]`
   - Match → `gPerRxOk++`，prints `RX OK #<seq>  rssi: -<val>`
   - Mismatch → prints `RX CRC ERR #<seq>  rssi: -<val>`
4. `gPerRxTotal++`
5. Prints running PER: `PER: <err>/<total> = <pct>%`
6. When `gPerRxTotal >= 500`: prints final summary and resets both counters

**PER formula:**

```
PER(%) = (gPerRxTotal - gPerRxOk) * 100 / gPerRxTotal
```

> **Note:** Completely lost packets produce no IRQ event and are not counted.
> The final total may be less than 500 if packets are lost before reaching the receiver.

## Extended Notes

### Common.h as the Single Include Entry
All `.c` files only need `#include "Common.h"` to get all typedefs, MCU headers, and module declarations.

### SPI Implementation
Uses **Software SPI (GPIO bit-bang)**. Pin definitions are centralized in `RF_Hal.h`:

[SPI Pin Assignment]
  NIRQ  P03  Interrupt input
  MOSI  P00  SPI data output
  MISO  P01  SPI data input
  SCK   P10  SPI clock
  NSS   P15  SPI chip select

### RF_RX_SIZE
`RF_RX_SIZE` in `RF_App.c` is the expected receive length passed to `TRx_RX_Trigger()`.
In transparent mode this must match the TX payload length.

### PER Counter Variables

- `gPerRxOk`    : number of packets received with correct XOR checksum
- `gPerRxTotal` : total number of packets received (ok + error)
- Both are reset to 0 after the final PER summary is printed

### Startup UART Log

On power-up, `main.c` outputs the project name and init result via UART:

  "TransTxRx_PER : init done\r\n"  — initialization successful
  "TransTxRx_PER : init fail\r\n"  — initialization failed

### XTAPP_Scan() Error Guard

`XTAPP_Scan()` returns immediately if `rf_err_mode == 1` (init failed), preventing RF access when the transceiver is not initialized.
