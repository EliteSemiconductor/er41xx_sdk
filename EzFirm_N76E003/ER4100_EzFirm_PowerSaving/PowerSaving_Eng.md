# ER4100_EzFirm_PowerSaving Project Structure

## Directory Tree

```
ER4100_EzFirm_PowerSaving/
│
├── Project/                          # Keil project files
│   ├── PowerSaving.uvproj           # Main project file
│   ├── PowerSaving.uvopt            # Project options
│   ├── STARTUP.A51                  # 8051 startup assembly
│   ├── Nu_Link_8051_Driver.ini      # Programmer settings
│   ├── LST/                         # Compiler output listing files (*.lst, *.map)
│   └── Output/                      # Build output (*.obj, *.hex, *.lnp)
│
├── Include/                          # MCU system headers (read-only, do not modify)
│   ├── N76E003.h                    # MCU register definitions
│   ├── SFR_Macro.h                  # SFR operation macros
│   └── Function_Define.h            # MCU function definitions
│
├── Common/                           # Shared libraries
│   ├── Common.h                     # Project-wide include entry: typedef, MCU header, all module headers
│   ├── Delay.h / Delay.c            # Delay functions
│   └── Uart.h / Uart.c              # UART TX/RX functions
│
├── User/                             # User application layer
│   └── main.c                       # Main entry: GPIO init, system init, main loop
│
└── RF Drivers/                       # RF driver layer
    ├── RF_Hal.h / RF_Hal.c          # RF HAL: pin definitions, software SPI bit-bang
    ├── RF_App.h / RF_App.c          # RF application: init, scan, IRQ handling, power management
    │
    └── ER4100Api/                   # ER4100 low-level SPI API (provided by ESMT)
        ├── SPI_ER41xx.h / .c        # SPI command set, register access, FIFO management
        └── SPI_ER41xx_config.h      # RF register initial values (generated by EzGen tool)
```

## Layer Architecture

```
User Application
  main.c
    │  GPIO init, system init, main loop
    ▼
RF Application Layer
  RF_App.c / RF_App.h
    │  Packet TX/RX, IRQ handling, power management state machine
    ▼
ER4100 SPI API
  SPI_ER41xx.c / SPI_ER41xx.h  ← SPI_ER41xx_config.h (register config)
    │  Register R/W, FIFO operations, mode switching
    │  Calls TRx_Write / TRx_Read for actual SPI transfer
    ▼
RF HAL Layer
  RF_Hal.c / RF_Hal.h
    │  SPI timing (Software bit-bang), pin definitions
    ▼
Hardware
  N76E003 GPIO → ER4100 RF IC (433 MHz)
```

## Extended Notes

### Common.h as the Single Include Entry
All `.c` files only need `#include "Common.h"` to get all typedefs, MCU headers, and module declarations.

### SPI Implementation
Uses **Software SPI (GPIO bit-bang)**. Pin definitions are centralized in `RF_Hal.h`:

[SPI Pin Assignment]
  NIRQ  P03  Interrupt input
  MOSI  P00  SPI data output
  MISO  P01  SPI data input
  SCK   P10  SPI clock
  NSS   P15  SPI chip select

### GPIO — Application Pins

[GPIO — Application Pins]
  P05  Push-pull  Power management button (active-low)
  P07  Push-pull  Deep sleep trigger button (falling-edge INT)
  P04  Quasi      Debug signal (default high)

P07 uses `Enable_BIT7_FallEdge_Trig` + `Enable_INT_Port0` + `set_EPI` for hardware pin interrupt.

### Power Management

`RF_App.c` implements a two-state power management machine:

[Power Management States]
  `active`    : RF chip running normally, RX enabled
  `deepsleep` : RF chip in power-down mode via `TRx_PowerDownMode()`

**State transitions:**
- `active → deepsleep`: P05 pressed while in active state
- `deepsleep → active`: RF chip asserts NIRQ with `IS_INT_ST_WAKEUP` event

**Button debounce:** After P05 action, `while(P05==0)` waits for button release, followed by `Delay_ms(20)` to suppress bounce.

### RF_RX_SIZE
`RF_RX_SIZE` in `RF_App.c` is the expected receive length passed to `TRx_RX_Trigger()`:
- **802.15.4 mode**: ignored; MAC layer reads actual length from PHR
- **Transparent mode**: must match expected payload length (standard: 1~128, long packet: 1~2047)

### Startup UART Log

On power-up, `main.c` outputs the project name and init result via UART:

  "PowerSaving : init done\r\n"  — initialization successful
  "PowerSaving : init fail\r\n"  — initialization failed

### XTAPP_Scan() Error Guard

`XTAPP_Scan()` returns immediately if `rf_err_mode == 1` (init failed), preventing RF access when the transceiver is not initialized.
