# ER4100_EzFirm_802154TxRx_CCA

## Overview

This project demonstrates **IEEE 802.15.4 mode TX with CCA (Clear Channel Assessment)** and RX using the ER4100 RF transceiver on an N76E003 (8051) MCU.

The device continuously listens in RX mode. Pressing the button (P0.5) triggers a CCA TX: the transceiver first measures ambient RSSI; if it is below the configured threshold, the packet is sent; if noise exceeds the threshold, TX is aborted and a failure message is printed via UART.

---

## CCA Mechanism

CCA prevents transmission when the channel is already occupied by noise above a set threshold.

```
CCA threshold register value = 0x0FFF - 8 × CCA_THRESHOLD_dBm
```

Default: `CCA_THRESHOLD = 80` dBm → register value `= 0x0FFF - 640 = 0x02BF`

Configured at init via:
```c
TRx_CCA_Config(0x0FFF - 8 * CCA_THRESHOLD);
```

TX result:
- Channel clear → transmit → `"CCA Tx done.\r\n"`
- Channel busy  → TX aborted → `"CCA Tx fail.\r\n"`

## 802.15.4 Packet Format

```
[PHR][MHR][PAYLOAD][CRC]
```

[Field Description]
  PHR      : 1 byte   Total packet length (MHR + PAYLOAD + CRC)
  MHR      : 15 bytes Hard-coded MAC Header (FrameCtrl, SeqNum, PAN ID, addresses)
  PAYLOAD  : variable  User payload (RF_TX_SIZE - MHR - CRC), **must be filled LSB-first**
  CRC      : 2 bytes   CRC-16, appended automatically by hardware

MHR template (`SamplePattern[]`):
```c
0x41,0xC8,0x00,       // [FrameCtrl:41C8][SeqNum:00]
0xCD,0xAB,0xFF,0xFF,  // [DestPAN_ID:ABCD][DestAddr:FFFF]
0x02,0x00,0x00,0xAB,  // [SrcAddr(LE): 0x000000AAAB000002]
0xAA,0x00,0x00,0x00,
```

> **Note:** In 802.15.4 RX mode, the length parameter of `TRx_RX_Trigger()` is ignored; the MAC layer reads the actual packet length from the PHR.

## Extended Notes

### Common.h as the Single Include Entry
All `.c` files only need `#include "Common.h"` to get all typedefs, MCU headers, and module declarations.

### SPI Implementation
Uses **Software SPI (GPIO bit-bang)**. Pin definitions are centralized in `RF_Hal.h`:

[SPI Pin Assignment]
  NIRQ  P03  Interrupt input
  MOSI  P00  SPI data output
  MISO  P01  SPI data input
  SCK   P10  SPI clock
  NSS   P15  SPI chip select

### CCA TX Flow

When P05 is pressed:
1. Print `"CCA Tx...\r\n"` via UART
2. Copy `SamplePattern[]` (MHR) into `gXtBuffer`
3. Write the incremented sequence number `gu8TxSeqNum++` into the first payload byte
4. Fill remaining payload bytes with sequential index values (`i`)
5. Call `XTAPP_SendDataCCA()` — triggers TX with CCA enabled (`TRx_TX_Trigger(len, 1)`)
6. Wait for NIRQ (`while(NIRQ_Value)`)
7. Check interrupt status:
   - `IS_INT_ST_TX` → channel was clear, TX succeeded → print dump buffer + `"CCA Tx done.\r\n"`
   - Otherwise (`IS_INT_ST_TXERR`) → channel too noisy → print `"CCA Tx fail.\r\n"`
8. Restart RX

### Startup UART Log

On power-up, `main.c` outputs the project name and init result via UART:

  "802154TxCCA : init done\r\n"  — initialization successful
  "802154TxCCA : init fail\r\n"  — initialization failed

### XTAPP_Scan() Error Guard

`XTAPP_Scan()` returns immediately if `rf_err_mode == 1` (init failed), preventing RF access when the transceiver is not initialized.
