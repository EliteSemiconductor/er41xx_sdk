# ER4100_EzFirm_RSSI_Scan

## Overview

This project demonstrates **ambient RSSI measurement** using the ER4100 RF transceiver's CCA (Clear Channel Assessment) function on an N76E003 (8051) MCU.

Every second, `XTAPP_Scan()` calls `TRx_GetRSSI_CCA()` to sample the current channel energy level and prints the result in dBm via UART. There is no packet TX or RX in this project — it measures background RF energy only.

RSSI conversion formula:

```
RSSI_dBm = -((4095 - raw) / 8)   [dBm]
```

---

## Test Environment Setup

To observe RSSI changes, a second ER4100 board running a known RF source is needed.

**Recommended: use `ER4100_EzFirm_SingleTone` as the RF source.**

[Setup]
  Board A  RSSI_Scan     → measures ambient RSSI, prints result every 1 s
  Board B  SingleTone    → transmits continuous carrier wave on the same frequency

With Board B transmitting, RSSI on Board A will rise significantly. Moving Board B closer or further away produces measurable RSSI changes. This makes it easy to verify the measurement range and sensitivity without building a packet TX/RX system.

> Board B must be configured to the **same channel/frequency** as Board A. Both projects use the same `SPI_ER41xx_config.h` register settings by default.

## Extended Notes

### Common.h as the Single Include Entry
All `.c` files only need `#include "Common.h"` to get all typedefs, MCU headers, and module declarations.

### SPI Implementation
Uses **Software SPI (GPIO bit-bang)**. Pin definitions are centralized in `RF_Hal.h`:

[SPI Pin Assignment]
  NIRQ  P03  Interrupt input
  MOSI  P00  SPI data output
  MISO  P01  SPI data input
  SCK   P10  SPI clock
  NSS   P15  SPI chip select

### Key API Functions

[Key API Functions]
  `TRx_CCA_Config(u16CCA_RSSITHD)` : Set CCA RSSI threshold (e.g. TX_CCA_RSSI_80dBmTHD)
  `TRx_GetRSSI_CCA(u16RSSI_dBm)`   : Trigger CCA measurement, return raw 16-bit RSSI value

### RSSI Output Format

Each measurement prints one line via UART:

  "rssi(dBm): -XX\r\n"

where `XX = (4095 - raw) / 8`. Larger raw value → lower dBm (weaker signal).

### Startup UART Log

On power-up, `main.c` outputs the project name and init result via UART:

  "RSSI_Scan : init done\r\n"  — initialization successful
  "RSSI_Scan : init fail\r\n"  — initialization failed

### XTAPP_Scan() Error Guard

`XTAPP_Scan()` returns immediately if `rf_err_mode == 1` (init failed), preventing RF access when the transceiver is not initialized.
