# ER4100 SDK_EZ

Distribution root for the ER4100 (ESMT) RF transceiver SDK: embedded firmware examples
plus the PC-side register configuration tool.

---

## Contents

- **[`EzFirm/`](EzFirm/README.md)** — Embedded firmware SDK targeting the Nuvoton N76E003
  (8051) MCU. 18 example projects covering Transparent, IEEE 802.15.4, NFC, and utility/test
  modes (WOR, PER, CCA, RSSI scan, power saving, etc.). See `EzFirm/README.md` for the full
  project list, hardware platform details, directory layout, and build instructions.
- **`EzCodeGen2_20260805_V2.2.exe`** — PC configuration tool (formerly EzGen). Reads a
  project's `.ini` file and generates `SPI_ER41xx_config.h` (RF register table) for that
  project. See `revise.txt` for what changed from EzGen V2.1.
- **`SPI_ER41xx_config_EzGen2.2.h`** — Sample header generated by EzCodeGen V2.2, kept here
  as a reference for the new `_D_CODE`-based format.
- **[`revise.txt`](revise.txt)** — Revision notes: SDK_EZ vs. the previous Lierda-specific
  delivery, and the EzGen → EzCodeGen tool update.

---

## Quick Start

1. Pick a project under `EzFirm/ER4100_EzFirm_<Variant>/`.
2. Open `Project/*.uvproj` in Keil uVision (8051 toolchain) and Build All (F7).
3. Flash `Project/Output/*.hex` via Nu-Link.
4. To regenerate a project's `SPI_ER41xx_config.h`, open its `.ini` file with
   `EzCodeGen2_20260805_V2.2.exe` and export the header.
