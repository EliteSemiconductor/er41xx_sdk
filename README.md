# ER4100 SDK_EZ  (v2.0)

SDK_EZ makes it easy to develop for the ESMT ER41xx series Sub-GHz RF transceivers on
low-end MCUs. It has two parts:

- **EzToolkit** — PC GUI tool. Configures RF parameters, generates the register header
  (`SPI_ER41xx_config.h`) and, over UART, controls the ER4100 DVB evaluation board for
  TX/RX testing.
- **EzFirm** — firmware examples for ER4100. Each project covers one chip feature and
  takes the header generated by EzToolkit.

> **SDK_EZ v2.0 changes:** EzGen / EzCodeGen has been replaced by **EzToolkit**, and EzFirm
> moves to **2.0** (N76E003 and Nano100 platforms). The previous `EzGen/` and
> `EzFirm_N76E003/` folders have been removed. See [`revise.txt`](revise.txt).

## EzToolkit

Windows GUI tool (.NET Framework 4.8 / WinForms). Together with the DVB evaluation board
(USB-to-UART) and EzFirm, it covers RF parameter setup, register generation, TX/RX testing,
frequency-offset calibration and freezing parameters for mass production.

**Parameter panel**
- **RF PARAM** — crystal (38.4 / 40 MHz, Gain, CapIO), frequency, TX power
  (PA Config / Power LV), GFSK modem (data rate / deviation), packet (Preamble / Syncword /
  sync error tolerance / LSB-MSB order)
- **FREQ TABLE** — multi-channel frequency table, packed into the generated arrays
- **TX FIFO MODE** — Transparent + Presync (recommended) / Transparent / 802.15.4
- **GPIO** — per-pin Mode / GIO Sel / Pull / Inversion; GIO functions (TR_BSY, TR_FSH,
  RX_SYNC, TX_EN, …) and interrupt events (`INT_ST_*`)
- **PCR** — power management (PCRMU) and SHD hardware shutdown

**DVB Tester panel** (DVB board required)
- **Packet TX** — Length / Seq / Payload / CRC, random payload, count / interval / Infinite
- **Continuous TX** — SingleTone or Pattern (Bit_01010101, PRBS9)
- **Packet RX** — OK / Err counters, RSSI scan
- **State Ctrl** — Idle / DeepSleep / Shutdown

**REG TABLE**
- View registers live, with category / filter views
- Read / write DVB registers over UART (Shift + click to select, **Write Multi**)
- **Generate** — C initialization arrays (`Initial_Reg_Array` + channel table) for EzFirm

Settings are saved / loaded as `.ini` files. Examples in `Tools/`:

- `EzToolkit_settings_TransTxRx.ini` : `TransTxRx` / `TransTxRx_CCIT` / `TransTxRx_CCIT_PER`
- `EzToolkit_settings_longPkt.ini` : `TransTxRx_LongPkt`
- `EzToolkit_settings_WOR.ini` : `TransWOR` / `TransWOR_Ack_CCIT`
- `EzToolkit_settings_802154.ini` : `802154TxRx` / `802154TxRx_Addressing`
- `EzToolkit_settings_GPIO0_TRBSY.ini` : `GIO_TRBSY`

## EzFirm 2.0 Examples

Every example is provided for both platforms:
`ER4100_EzFirm_B_N76_<Variant>` (N76E003) and `ER4100_EzFirm_B_DVB_<Variant>` (Nano100).

- `TransTxRx` : Basic Transparent-mode TX/RX
- `TransTxRx_CCIT` : Transparent TX/RX with sequence number and software CRC-CCITT check
- `TransTxRx_CCIT_PER` : Packet Error Rate test based on `TransTxRx_CCIT`
- `TransTxRx_LongPkt` : Long-packet TX/RX (512-byte payload) using FIFO threshold handling
- `TransWOR` : Wake-on-Radio receive
- `TransWOR_Ack_CCIT` : Wake-on-Radio receive with CRC-CCITT check and automatic `"ACK"` reply
- `802154TxRx` : IEEE 802.15.4 TX/RX
- `802154TxRx_Addressing` : IEEE 802.15.4 PAN ID / address filtering (matched and broadcast frames)
- `SingleTone` : Continuous carrier output for RF testing
- `RSSI_Scan` : Background RF energy (RSSI) scan, printed every 1 s
- `GIO_TRBSY` : Switch GPIO0 to TR_BSY output via UART commands to observe TX/RX busy timing

How to run each example (buttons, UART commands, peer board, program flow):
[`Reference Code/FirmList.md`](Reference%20Code/FirmList.md).

Project layout: `User/` (main), `RF Drivers/` (`RF_App`, `RF_Hal`, `ER4100Api/SPI_ER41xx*`),
`Common/` (UART, delay), plus `Project/` (8051, `.uvproj`) or `Keil/` (M0, `.uvprojx`).

## Quick Start

1. Connect the DVB board, open **EzToolkit** from `Tools/` and load the example `.ini` that
   matches your project. Adjust the RF parameters and verify TX/RX in the DVB Tester panel.
2. In REG TABLE, click **Generate** and put the generated file in the project's
   `RF Drivers/ER4100Api/` folder (replacing `SPI_ER41xx_config.h`).
3. Open the Keil project and Build All (F7):
   - N76E003: `Project/*.uvproj` (Keil C51)
   - Nano100: `Keil/*.uvprojx` (Keil MDK-ARM)
4. Flash the output via Nu-Link.

### Notes

- **PA Config must match the PCB matching network.** Setting 23 dBm (H-PA) on L-PA hardware
  causes impedance mismatch and can damage the PA. To reduce power, lower Power LV instead.
- **CapIO** is the frequency-offset calibration parameter; calibrate it with a spectrum
  analyzer and fix the value before mass production.
- The DVB board supports **Transparent + Presync** only; the DVB Band setting is for the
  evaluation board and has no effect in production firmware.
- The FREQ TABLE stores frequencies only; data rate, deviation, power and syncword follow
  the global RF PARAM settings.
- GPIO1 SHD needs PCR Enable + Shutdown to be turned on. Internal test GPIO modes
  (RX_RF / RX_BBP / NFC / Debug) must not be used in production.

See the SDK_EZ User Guide in [`Application Note/`](Application%20Note/) for full instructions.
